# Codie's Illustrator Lessons

A Claude Cowork tutor kit: Codie's personal Claude instance teaches them
Adobe Illustrator, migrating from MS Paint pen-on-screen drawing. The
curriculum is built around Codie's own art style — black ink silhouettes,
thorn vines, briar wreaths, trees, crystals.

## For Codie

Open Claude (Cowork) on this folder and say **hi**. That's it — your tutor
knows where you're up to and takes it from there. Any day you'd rather just
draw something, say so and it becomes the lesson.

One habit to remember: after an exercise, press `Win+Shift+S`, drag over
your Illustrator canvas, and save the screenshot into `screenshots/` so
Claude can see your work.

## What's in here

| File / folder | What it is |
|---|---|
| `CLAUDE.md` | the tutor — loads automatically when Claude opens this folder |
| `LESSON-PLAN.md` | the 8-session curriculum |
| `PROGRESS.md` | where Codie is up to (the tutor keeps this updated) |
| `my-paint-art/` | Codie's original MS Paint pieces (tutor treats as read-only) |
| `screenshots/` | canvas screenshots for the tutor to look at |
| `exports/` | finished PNG/SVG exports |
| `projects/` | Illustrator `.ai` working files |

## For Stephen

Full setup steps live in the Obsidian vault:
`30-Projects/Codie Illustrator Lessons/Setup Guide.md`. Short version: put
Codie's MS Paint art into `my-paint-art/`, verify pen pressure works in
Illustrator, and teach the screenshot habit. The tutor logs anything that
needs admin attention under "Parked problems for Stephen" in `PROGRESS.md`.
